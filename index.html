Jun 2026 to Jul 2026 Internship

Research Intern, Diagnosis-Aware Compressive Sensing for Wearable ECG

National Institute of Technology (NIT), Silchar

  • Built and trained an end-to-end deep compressive sensing pipeline in PyTorch across 3 public ECG databases (PTB-XL, MIT-BIH, PTB Diagnostic), covering roughly 200,000 heartbeat segments, with every result repeated over 3 seeds and every notebook validated end to end on synthetic data before it was run for real.
  • Replaced the random sensing matrix the field uses by default with a learned one, cutting reconstruction error from 11.61% to 5.98% PRD at 10x compression at identical cost on the device.
  • Showed that reconstruction quality is a weak proxy for diagnosis: across compression ratios 5 to 30 the error rose 14x and crossed the accepted clinical threshold while classification accuracy held, with the loss falling almost entirely on one rare beat class.
  • Built the pipeline as three stages trained together: a learned sensing step that reduces to one matrix multiply over 1024-sample windows on the device, a 10-stage decoder with 670,418 parameters that rebuilds the signal at the receiver, and a convolutional classifier that makes the diagnostic call.

2026

EpiDetect

Machine Learning Seizure Detection System

Built an EEG seizure detection pipeline on the Bonn University benchmark (500 signals, 4:1 class imbalance), reaching 99.40% accuracy and 99.90% AUC-ROC under 10-fold stratified cross-validation, with 3 errors across all 500 signals. Engineered a 720-feature representation per signal across wavelet, time, spectral and nonlinear domains, with feature selection run inside each fold so nothing from the test data leaked into training. Combined 8 classifier families across 5 random seeds into a 40-model soft-voting ensemble with class weighting for the imbalance, then added SHAP and permutation importance so every prediction can be traced back to the features driving it.
